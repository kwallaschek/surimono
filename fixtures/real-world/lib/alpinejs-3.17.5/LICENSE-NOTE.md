# Alpine.js licence note

Alpine.js 3.17.5 is MIT (`"license": "MIT"`, `"author": "Caleb Porzio"` in the
package's `package.json`), but its npm tarball carries no licence file, nor do
the `@alpinejs/*` plugin tarballs checked. The upstream `LICENSE.md`
(https://github.com/alpinejs/alpine, commit
8d3d9a2f98385d4c879f4b5be080a0221279ed4d) has to be copied here from the source
repository; until then this note stands in, and no licence text was invented.
`dist/cdn.min.js` here is the unmodified npm file, used by a test fixture only.
