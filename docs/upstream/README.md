# Upstream drafts

Changes surimono needs in Blitz, fulgur or rquickjs. Each one is applied locally
through a `[patch]` in the root `Cargo.toml` and drafted here as an issue or pull
request text. Kay files them; the fleet never opens issues or pull requests on
other projects.

One file per change: `<project>-<short-name>.md` with the problem, the minimal
patch, the test that shows it, and the local `[patch]` it replaces.

quickjs-ng changes are carried in `vendor/rquickjs-sys` (see its `PATCHES.md`) and were reported to the maintainers privately.
